# Project summary

This repository is an independent reproduction-and-extension study of Fan, Wu, Yang, and Zhong's time-varying minimum-variance portfolio (TV-MVP). The complete author MATLAB/R release is preserved under `original_author_code/`; the new reproducible Python project uses one `config.yaml`, fixed seeds, tests, frozen market data, result tables, plots, and a run manifest.

The project implements four strategies: equal weight; an author-style TV-MVP with local PCA loadings, constant factor covariance, and sparse residual covariance; an otherwise identical TV-MVP with EWMA dynamic factor covariance; and a long-only, 10%-capped empirical 95% CVaR portfolio. CVaR scenarios are circular moving-block bootstrap draws of paired estimated factor scores and residual vectors, mapped through the current loading. All rolling estimates use only information available by month-end; weights take effect on the next trading day. Positive definiteness is checked and repaired by documented eigenvalue clipping when necessary.

The empirical snapshot contains 39 long-history current NIFTY 50 stocks. A 504-day rolling window and monthly rebalancing produce 2,362 out-of-sample days from February 2017 through August 2026. At 10 bp per one-way traded notional, equal weight has the strongest realised return and Sharpe. Dynamic factor covariance is nearly indistinguishable from the original TV-MVP. CVaR slightly lowers full-sample volatility and ES but sacrifices return and does not improve drawdown.

Statistical inference uses paired monthly losses and 1,999 three-month moving-block bootstrap draws. The pre-specified original-vs-dynamic and dynamic-vs-CVaR differences in volatility, ES, and net return all have 95% intervals containing zero. A separately bootstrapped high-volatility interaction test also finds no larger dynamic-covariance benefit. Diagnostics show heavy-tailed factor scores/residuals and unstable loading spaces.

The initially reported post-COVID CVaR comparison was confounded by constraints. A definitive matched run makes every optimizer long-only and 10%-capped. Under this fair design, baseline CVaR has lower return and higher volatility/ES than both covariance MVPs; block-bootstrap risk differences versus each MVP are statistically distinguishable. CVaR lowers fitted scenario tail loss but the ordering reverses out of sample, identifying scenario-tail overfit and calibration failure.

A pre-specified repair whitens historical factor/residual shocks, rescales them to current covariance, overweights recent blocks, adds explicit volatility/correlation stress draws, and penalises turnover/concentration. Post-2021, this raises CVaR net return from 10.17% to 14.30%, reduces turnover from 4.75 to 3.50 annually, and nearly removes average tail-calibration bias. Relative to matched original MVP, it has higher return/Sharpe but slightly higher daily volatility/ES; paired monthly confidence intervals include zero. Thus the repair is promising in this sample, not a demonstrated superior method. See reports 05 and 06.

Three stress designs—Gaussian, Student-t, and abrupt volatility/correlation shifts—use 100 independent replications each and known covariance matrices. Dynamic EWMA covariance does not consistently beat the benchmark; CVaR helps more often under the abrupt shift but fails to dominate elsewhere. Sensitivity checks across decay, factor count, window, CVaR confidence, and costs reinforce the honest conclusion: the extensions are methodologically valid and reproducible, but this evidence does not demonstrate reliable superiority or future profitability.
